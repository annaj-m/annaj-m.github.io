Featured project

The Autumn Collection

I designed and built the launch of a sixteen-painting collection for my own art shop, from the first painting to the finished collection page.

The goal

A store experience that feels like my Pinterest boards. Visitors who click a pin should land somewhere familiar and be able to browse all sixteen pieces in one place.

What I made

Sixteen animal paintings in a shared autumn palette, each sold as its own print. A homepage banner, a full collection page styled like my Pinterest pin overview, highlights on the Shop All page and the main menu, and matching banners for Etsy and Pinterest.

Key design decisions

  • Match the pins. Each print shows its Pinterest pin on its own soft pastel color.
  • Let the art lead. Titles are already on the pins, so the cards stay clean.
  • One layout, three places. A short home page banner and a full four-column page come from the same section.
  • Keep the current work on top. The newest collection comes first on the page.

Under the hood

A custom Shopify section I coded

The collection page runs on a section I wrote in Liquid, Shopify's template language.

  • One section, two layouts: a banner for the home page and a full collection page.
  • Editable in the theme editor: heading, columns, spacing, button and which collection to show.
  • Picks each product's pin image automatically, with the main photo as a backup.
  • Responsive grid: 4 columns on desktop, 3 on tablet, 2 on phone.
  • Lazy-loaded images in several sizes so the page stays fast.
